- When the repo contains both a **frontend** and a **backend/API** (for example: separate `frontend`/`backend` or `client`/`server` folders, directories like `api` or `server`, or multiple `package.json` files), you MUST make sure there is a **single dev/start script from the project root** that starts everything needed (both frontend and backend) so **Run in StackBlitz** spins up the whole stack at once. Prefer tools like `concurrently`, `npm-run-all`, workspaces, or a custom dev script that orchestrates both servers. Do **not** leave this for the user to request later—always add and/or update the scripts so StackBlitz runs real frontend + backend using the repo code and data.
