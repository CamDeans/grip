# AI-Driven Git Repository Analysis System

A Next.js application that leverages AI to analyze GitHub repositories and generate insights.

## Features

- 🔐 Authentication with NextAuth.js (GitHub OAuth and credentials)
- 📊 Real-time dashboard with WebSocket updates
- 🤖 AI-powered repository analysis using Claude
- 👥 Project collaboration
- 📝 Real-time code preview
- 📱 Responsive design with Tailwind CSS

## Prerequisites

- Node.js 16+
- MongoDB database
- GitHub OAuth application
- Anthropic API key
